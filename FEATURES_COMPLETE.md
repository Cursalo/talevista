## ✨ Core Features

### 1. AI Story Generation
- **Gemini AI Integration** - Advanced story generation
- **Multiple genres** - Fantasy, Sci-Fi, Mystery, Romance, Horror, Adventure, Historical, Cyberpunk
- **Writing styles** - Descriptive, Action-packed, Dialogue-heavy, Poetic, Minimalist
- **Tone control** - Light, Balanced, Dark, Inspiring, Mysterious
- **Length options** - Short (3-5 chapters), Medium (6-10), Long (11+)

### 2. Image Generation
- **Replicate Integration** - High-quality SDXL images
- **fal.ai Integration** - Ultra-fast image generation
- **Multiple models** - SDXL, Fast Lightning SDXL
- **Consistent characters** - Character sheet generation
- **Scene illustrations** - Chapter-specific images
- **Custom prompts** - User control over image generation

### 3. Voice Narration (ElevenLabs)
- **9+ AI voices** - Rachel, Antoni, Josh, Bella, Domi, Elli, Arnold, Adam, Sam
- **Voice customization** - Stability, similarity, style controls
- **Chapter narration** - Generate audio for any chapter
- **Playback controls** - Play, pause, download
- **Voice preview** - Test voices before generating
